# Project Context — C197 Claude Microsoft 365 Masterclass

## Purpose

Generate and maintain the complete aligned courseware package for the one-day non-WSQ course **Claude Microsoft 365 Masterclass (C197)**.

## Current release

- Version: 2.0
- Date: 12 August 2026
- Duration: 7.5 instructional hours
- Delivery: instructor-led company-scenario workshops and hands-on labs
- Trainer: Jim Gan Chiu Liang (JL)

## Single-company narrative

Learners join the Business Transformation Office of **Lumina Living Pte Ltd**, a fictional Singapore omnichannel home-and-lifestyle company. They build one connected FY2027 planning and management pack covering:

1. governed Claude and Microsoft 365 setup;
2. marketing, strategy, sustainability and HR work;
3. financial analysis, Excel dashboard and executive PowerPoint; and
4. Outlook, Claude Cowork and Claude Code coordination.

## Artifact contract

- Main deck: visual concepts and process maps, realistic Office samples and prompt examples; no click-by-click procedures.
- Learner Guide: complete procedures, prompts, commands, checks and troubleshooting.
- Lesson Plan: exact schedule and activity alignment.
- Labs: 11 individual self-contained folders, each with a README, DOCX, XLSX, PPTX and templates.
- All artifacts are generated from the canonical course data and domain modules under `.claude/skills/non-wsq-courseware-build/build/`.

## Security boundary

The trainer-supplied classroom accounts are stored only in ignored `.env.training`. Courseware, labs, screenshots, Drive and GitHub use placeholders and private trainer hand-off instructions. Outlook outputs remain drafts until a human selects Send; connector and Claude Code actions use least privilege and explicit approvals.
