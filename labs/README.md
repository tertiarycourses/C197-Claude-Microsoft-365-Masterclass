# Labs — Claude Microsoft 365 Masterclass (C197)

**Course Code:** C197  |  **Version v3.0 · 13 August 2026**

All 16 activities use one fictional company, **Lumina Living Pte Ltd**, and build a connected FY2027 planning and management pack.

The presentation explains concepts, decisions, process maps and realistic work samples. These lab folders and the Learner Guide contain the complete prompts, commands and verification checks.

## Lab folder standard

Every lab folder contains a detailed README, a realistic company Word brief, an Excel working file, an editable PowerPoint starter and reusable review/approval templates. Lab 11 also contains safe local automation starters.

## Lab sequence

| Topic | Lab | Activity | Company outcome |
|---|---:|---|---|
| 01 | 00 | [Set Up Claude for Microsoft 365](lab-00-set-up-claude-for-microsoft-365/README.md) | A completed setup checklist showing which of the four routes are ready, and what to do about any that are not. |
| 01 | 01 | [Shortlist Candidates with AI Experience](lab-01-screen-candidates-in-excel/README.md) | A saved shortlist in your own workbook, a second copy saved from the Desktop app, and one sentence on which way suits work that must stay in one file. |
| 01 | 02 | [Analyse Staff Data and Decide What Claude May Read](lab-02-analyse-staff-data-in-excel/README.md) | A summary table and chart built by Claude in your own workbook, plus a completed access table. |
| 01 | 03 | [Ask Claude Clearly](lab-03-ask-claude-clearly-in-word/README.md) | A new section written into the brief by Claude, a second copy produced by the Desktop app, and a completed request checklist. |
| 02 | 04 | [Write a Hiring Plan in Word](lab-04-write-a-hiring-plan-in-word/README.md) | A hiring plan section written into the brief, and a separate Lumina-Living-FY2027-Hiring-Plan.docx ready for the Head of HR. |
| 02 | 05 | [Build an HR Policy Skill from Your Real Policies](lab-05-draft-hr-policy-in-word/README.md) | An hr-policy-draft skill built from your real policy library and template, and two new policies on the company letterhead. |
| 03 | 06 | [Build a Headcount Analysis in Excel](lab-06-build-a-headcount-analysis-in-excel/README.md) | An analysis sheet where every result is a formula that points back to the source data. |
| 03 | 07 | [Build a Leadership Deck Two Ways](lab-07-build-a-leadership-update-in-powerpoint/README.md) | Two versions of the same six-slide update: one built in the panel with a linked Excel chart, one built end to end by Claude Desktop. |
| 04 | 08 | [Sort the HR Inbox and Draft One Reply](lab-08-sort-the-hr-inbox-and-draft-one-reply/README.md) | Every message sorted, one reply drafted, the person who would approve it named, and the reply created as an Outlook draft ready for review. |
| 04 | 09 | [Read a Whole Folder and Write the Summary](lab-09-read-a-folder-and-write-a-summary/README.md) | A two-page people summary built only from the folder, naming the file behind every claim, with disagreements reported rather than settled. |
| 04 | 10 | [Draft an Outlook Reply with Claude in Chrome](lab-10-draft-outlook-replies-with-chrome/README.md) | A reviewed reply drafted in Outlook on the web, sent only after you approved it or deliberately left in Drafts. |
| 04 | 11 | [Build a Daily HR Routine with Cowork](lab-11-build-a-daily-hr-routine-with-cowork/README.md) | A written daily routine covering inbox, reporting and chasing; this week's work assigned an owner and a deadline; and today's daily HR report. |
| 04 | 12 | [Automate an HR Pipeline with a Project](lab-12-automate-an-hr-pipeline-with-a-project/README.md) | A Lumina Living HR project with materials and standing instructions, and a new starter pipeline run twice from it. |
| 04 | 13 | [Add Skills and Connectors to the Project](lab-13-add-skills-and-connectors-to-the-project/README.md) | An HR project with materials, standing rules, a skill and a connector, running one request that produces a policy draft, a summary and an Outlook draft. |
| 04 | 14 | [Upload a Shared Skill for Slides](lab-14-upload-a-shared-skill-for-slides/README.md) | An uploaded deck-design-standard skill, and a rebuilt deck where every title states a conclusion. |
| 04 | 15 | [Use the Skill from Word Without Opening Excel](lab-15-use-a-skill-across-excel-and-word/README.md) | A completed quarterly update with figures drawn from the workbook, saved as a final copy. |
