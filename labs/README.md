# Labs — Claude Microsoft 365 Masterclass (C197)

**Course Code:** C197  |  **Version v1.0 · 27 July 2026**

All 8 labs build a **single connected deliverable** — the quarterly business-review pack for the fictional retailer **Lumina Living** — which you write, analyse, present and send using Claude alongside Microsoft 365 across the day, starting in Lab 1 and sending it out in Lab 8. Wherever possible, use your own non-confidential work; the Lumina Living sample material is provided for everyone to follow along. There is **no assessment** — each lab verifies itself with a 'Test it' step.
